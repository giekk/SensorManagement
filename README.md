# SensorManagement

SensorManagement è un progetto del secondo anno di Informatica all'Università di Padova nel corso di Programmazione ad Oggetti.
Si tratta di un'applicazione per la gestione di sensori atmosferici di vario tipo scritta in C++ con l'utilizzo del framework Qt.
La versione di Qt utilizzata è la 6.7.2.

Per ulteriori dettagli sul progetto leggere il file Relazione.pdf.
